Frequently Asked Questions

Microsoft Edge says the file "isn't commonly downloaded" or "blocked"?

This is Microsoft SmartScreen's standard warning for brand-new open-source utility zip packages containing setup scripts. To proceed: hover over the download in Edge → click … (3 dots) → select Keep → click Show more → click Keep anyway. You can also download directly from our official GitHub mirror above.

Why does TubeGrab use a desktop helper?

YouTube streams 1080p, 1440p, and 4K video separately from audio. Standard browser extensions cannot merge them without freezing. The TubeGrab helper muxes them losslessly via FFmpeg.

How do I update TubeGrab?

Inside your Windows Suite folder, simply double-click update.bat. It pulls the latest YouTube extraction algorithms in 3 seconds.

Is it completely free?

Yes. TubeGrab is 100% free and open-source under the MIT License with no ads, tracking, or account requirements.
